# [912. Sort an Array](https://leetcode.com/problems/sort-an-array/)

## Описание задачи

Дан массив целых чисел `nums`. Необходимо отсортировать массив в порядке возрастания и вернуть его.

Вы должны решить задачу, не используя встроенные функции сортировки языка программирования.

**Пример 1:**

- **Input:** nums = [5,2,3,1]
- **Output:** [1,2,3,5]

---

## Мой подход к решению: Сортировка слиянием (Merge Sort)

### 1. Размышления (Thought Process)

- Алгоритмы вроде сортировки выбором (Selection Sort) или пузырьком работают за $O(N^2)$ и не проходят по времени (Time Limit Exceeded) на массивах из 50 000 элементов.
- Нам нужен алгоритм со сложностью $O(N \log N)$. Отлично подойдет **Сортировка слиянием (Merge Sort)**, так как она стабильна и не имеет худшего случая $O(N^2)$, в отличие от базовой Быстрой сортировки (QuickSort).
- **Стратегия "Разделяй и властвуй":**
  1. Разделяем массив пополам, пока не получим массивы длиной в 1 элемент (массив из 1 элемента по определению отсортирован).
  2. Берем два отсортированных массива и сливаем их в один с помощью двух указателей (паттерн, знакомый по задаче слияния связных списков).

### 2. Алгоритм

1. **Базовый случай:** Если длина `nums` меньше или равна 1, просто возвращаем `nums`.
2. **Разделение:** Находим середину `mid = len(nums) // 2`. Рекурсивно вызываем `sortArray` для левой половины `left_half` и правой половины `right_half`.
3. **Слияние:** Создаем вспомогательную функцию `merge(left, right)`.
   - Инициализируем два указателя `i = 0` (для левого) и `j = 0` (для правого), а также пустой массив `merged`.
   - Пока `i < len(left)` и `j < len(right)`: сравниваем элементы. Меньший добавляем в `merged` и сдвигаем соответствующий указатель.
   - Когда один из массивов закончится, добавляем остаток другого массива в конец `merged`.
4. Вернуть результат функции `merge`.

---

## Анализ сложности

- **Сложность по времени (Time Complexity):** $O(N \log N)$. Массив делится пополам $\log N$ раз. На каждом уровне разделения мы тратим $O(N)$ операций на слияние всех частей обратно.
- **Сложность по памяти (Space Complexity):** $O(N)$. Нам требуется дополнительная память для создания массивов при слиянии, а также память под стек рекурсивных вызовов.

# [349. Intersection of Two Arrays](https://leetcode.com/problems/intersection-of-two-arrays/)

## Описание задачи

Даны два целочисленных массива `nums1` и `nums2`. Необходимо вернуть массив, представляющий их пересечение (элементы, которые присутствуют в обоих массивах).

Каждый элемент в результирующем массиве должен быть **уникальным**, и результат можно вернуть в **любом порядке**.

**Пример 1:**

- **Input:** nums1 = [1,2,2,1], nums2 = [2,2]
- **Output:** [2]

**Пример 2:**

- **Input:** nums1 = [4,9,5], nums2 = [9,4,9,8,4]
- **Output:** [9,4]
- **Пояснение:** Элементы 4 и 9 есть в обоих массивах. Ответ [4,9] также принимается.

---

## Мой подход к решению

### 1. Размышления (Thought Process)

- **Подход "в лоб" (Brute-force):** Для каждого элемента из `nums1` мы могли бы запускать цикл по `nums2` и искать совпадения. Это дало бы квадратичную сложность **O(N \* M)**, где N и M — длины массивов.
- **Использование Множеств (Hash Set):** Нам нужно проверять, существует ли элемент, за время **O(1)**. Для этого мы можем преобразовать один из массивов (например, `nums1`) во множество.
- **Алгоритм поиска:** Проходим по второму массиву `nums2`. Если текущее число есть в нашем множестве, значит, это пересечение!
- **Уникальность результата:** Так как в `nums2` тоже могут быть дубликаты (как во втором примере с девятками и четверками), мы должны складывать найденные пересечения не в обычный список, а в еще одно результирующее множество.
- _Примечание для Python:_ В Python эту задачу можно решить в одну строку, используя встроенную операцию пересечения множеств: `return list(set(nums1) & set(nums2))`. Однако на собеседованиях часто просят реализовать логику руками, чтобы показать понимание работы алгоритма. Мы напишем ручной вариант, основанный на хеш-множествах.

### 2. Алгоритм

1. Преобразовать массив `nums1` во множество `set1` для быстрого поиска.
2. Создать пустое множество `result_set` для хранения уникальных ответов.
3. Запустить цикл по каждому числу `num` в массиве `nums2`:
   - Если `num` присутствует в `set1`, добавить его в `result_set`.
4. Преобразовать `result_set` в список и вернуть его.

---

## Анализ сложности

- **Сложность по времени (Time Complexity):** **O(N + M)**, где N и M — длины массивов `nums1` и `nums2`. Преобразование `nums1` во множество занимает O(N). Затем мы делаем один проход по `nums2` за O(M), где каждая проверка в `set1` занимает константное время O(1).
- **Сложность по памяти (Space Complexity):** **O(N)** (или O(min(N, M)), если оптимизировать выбор массива для множества). Нам требуется дополнительная память для создания множества из элементов первого массива, а также для результирующего множества.

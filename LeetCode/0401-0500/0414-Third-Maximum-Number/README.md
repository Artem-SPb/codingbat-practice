# [414. Third Maximum Number](https://leetcode.com/problems/third-maximum-number/)

## Описание задачи

Дан массив целых чисел `nums`. Необходимо вернуть **третье по величине уникальное** число в этом массиве.

Если третьего максимума не существует (в массиве меньше трех уникальных чисел), нужно вернуть самый большой (первый) максимум.

**Строгое ограничение:** Вы должны решить задачу за время **O(N)**.

**Пример 1:**

- **Input:** nums = [3,2,1]
- **Output:** 1
- **Пояснение:** Первый максимум — 3, второй — 2, третий — 1.

**Пример 2:**

- **Input:** nums = [1,2]
- **Output:** 2
- **Пояснение:** Третьего максимума нет, поэтому возвращаем первый максимум (2).

**Пример 3:**

- **Input:** nums = [2,2,3,1]
- **Output:** 1
- **Пояснение:** Уникальные числа: [3, 2, 1]. Третий максимум — 1. Дубликаты игнорируются.

---

## Мой подход к решению

### 1. Размышления (Thought Process)

- **Проблема сортировки:** Если мы отсортируем массив, это займет `O(N log N)` времени, а от нас требуют `O(N)`.
- **Логика сортировки выбором:** Мы можем завести три переменные: `max1`, `max2` и `max3`. По мере прохождения массива мы будем "выбирать" подходящие числа и обновлять наш пьедестал почета.
- **Сдвиг пьедестала:** Если мы находим число, которое больше чемпиона (`max1`), чемпион сдвигается на второе место, второе место уходит на третье, а новое число становится чемпионом. Если число попадает между первым и вторым местом — сдвигаем только нижнюю часть.
- **Дубликаты:** Условие требует _уникальных_ максимумов. Значит, если текущее число уже занимает одно из мест на нашем пьедестале, мы его просто игнорируем.

### 2. Алгоритм

1. Инициализировать переменные `m1`, `m2`, `m3` значением минус бесконечность (`-infinity`).
2. Запустить цикл по каждому числу `num` в массиве `nums`:
   - Если `num` равно `m1`, `m2` или `m3` — пропустить шаг (защита от дубликатов).
   - Если `num > m1`: сдвинуть `m3 = m2`, `m2 = m1` и записать `m1 = num`.
   - Иначе, если `num > m2`: сдвинуть `m3 = m2` и записать `m2 = num`.
   - Иначе, если `num > m3`: записать `m3 = num`.
3. В конце проверить: если `m3` всё ещё равно минус бесконечности, значит, 3-го уникального максимума не было. Вернуть `m1`. Иначе вернуть `m3`.

---

## Анализ сложности

- **Сложность по времени (Time Complexity):** **O(N)**, где N — длина массива. Мы проходим по массиву ровно один раз. Внутри цикла выполняется несколько простых сравнений `O(1)`.
- **Сложность по памяти (Space Complexity):** **O(1)**. Мы используем только три переменные для хранения максимумов.

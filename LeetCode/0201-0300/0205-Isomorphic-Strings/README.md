# [205. Isomorphic Strings](https://leetcode.com/problems/isomorphic-strings/)

## Описание задачи

Даны две строки `s` и `t`. Определите, являются ли они изоморфными.

Две строки `s` и `t` изоморфны, если символы в `s` можно заменить так, чтобы получить `t`.
Все вхождения символа должны быть заменены на другой символ при сохранении порядка символов. Никакие два символа не могут отображаться в один и тот же символ, но символ может отображаться сам в себя.

**Пример 1:**

- **Input:** s = "egg", t = "add"
- **Output:** true
- **Пояснение:** 'e' заменяется на 'a', а 'g' на 'd'.

**Пример 2:**

- **Input:** s = "foo", t = "bar"
- **Output:** false
- **Пояснение:** 'o' не может быть одновременно заменено на 'a' и 'r'.

**Пример 3:**

- **Input:** s = "paper", t = "title"
- **Output:** true

---

## Мой подход к решению

### 1. Размышления (Thought Process)

- **Идея маппинга:** Нам нужно запоминать, какая буква из первой строки соответствует букве из второй. Для этого идеально подходит хеш-таблица (словарь). Если мы встречаем букву `'e'` и решаем, что она теперь `'a'`, мы записываем это в словарь: `map['e'] = 'a'`.
- **Проверка противоречий:** Если мы снова встречаем `'e'`, мы смотрим в словарь. Если там записано, что `'e'` должно стать `'a'`, а в текущей позиции строки `t` стоит другая буква — значит, строки не изоморфны.
- **Проблема двусторонней связи:** Условие гласит: _"Никакие два символа не могут отображаться в один и тот же символ"_. Это значит, что если `'e'` -> `'a'`, то другая буква, например `'x'`, уже не может превратиться в `'a'`.
- **Решение:** Нам нужно два словаря (или один словарь и одно множество).
  1. `map_s_to_t`: отслеживает, во что превращаются буквы из `s`.
  2. `map_t_to_s`: отслеживает, какие буквы из `t` уже были заняты буквами из `s` (обратная связь).

### 2. Алгоритм

1. Создать два пустых словаря: `map_s_to_t` и `map_t_to_s`.
2. Запустить цикл, параллельно проходя по символам обеих строк (например, используя `zip(s, t)` в Python).
3. На каждом шаге получаем `char_s` и `char_t`:
   - Если `char_s` уже есть в `map_s_to_t` и его значение не равно `char_t` — вернуть `False`.
   - Если `char_t` уже есть в `map_t_to_s` и его значение не равно `char_s` — вернуть `False`.
   - Если противоречий нет, записываем связи: `map_s_to_t[char_s] = char_t` и `map_t_to_s[char_t] = char_s`.
4. Если цикл завершился без ошибок, вернуть `True`.

---

## Анализ сложности

- **Сложность по времени (Time Complexity):** **O(N)**, где N — длина строк. Мы проходим по строкам ровно один раз. Поиск и вставка в хеш-таблицу работают за O(1).
- **Сложность по памяти (Space Complexity):** **O(1)**. Несмотря на создание двух словарей, их максимальный размер ограничен размером алфавита (например, 256 символов ASCII). Константная память не зависит от длины входной строки.

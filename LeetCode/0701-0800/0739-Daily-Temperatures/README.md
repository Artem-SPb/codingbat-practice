# [739. Daily Temperatures](https://leetcode.com/problems/daily-temperatures/)

## Описание задачи

Дан массив целых чисел `temperatures`, представляющий ежедневную температуру.
Необходимо вернуть массив `answer`, где `answer[i]` — это количество дней, которое вам нужно подождать после `i`-го дня, чтобы наступил более теплый день.

Если в будущем такого дня не предвидится (более теплого дня больше не будет), оставьте `answer[i] == 0`.

**Пример 1:**

- **Input:** temperatures = [73,74,75,71,69,72,76,73]
- **Output:** [1,1,4,2,1,1,0,0]

**Пример 2:**

- **Input:** temperatures = [30,40,50,60]
- **Output:** [1,1,1,0]

**Пример 3:**

- **Input:** temperatures = [30,24,21]
- **Output:** [0,0,0]

---

## Мой подход к решению

### 1. Размышления (Thought Process)

- **Подход "в лоб":** Для каждого дня запускать внутренний цикл, который будет смотреть вперед и искать первый день с температурой выше текущей. Это займет время O(N^2), и на массиве из 100 000 дней алгоритм зависнет (Time Limit Exceeded).
- **Концепция Стека (Stack):** Стек работает по принципу LIFO (Last In, First Out — Последним пришел, первым ушел). Представьте стопку тарелок: вы кладете тарелку наверх и берете тоже сверху.
- **Монотонный убывающий стек:** Мы будем идти по массиву температур и складывать в стек **индексы** дней, для которых мы _еще не нашли_ более теплого дня.
- Как только мы встречаем день `X`, который **теплее**, чем день на вершине нашего стека, происходит магия! Это значит, что для дня на вершине стека ожидание закончилось.
  1. Мы достаем индекс старого дня из стека.
  2. Вычисляем разницу между текущим днем `X` и старым днем (это и есть количество дней ожидания).
  3. Записываем эту разницу в ответ.
  4. Повторяем это, пока текущий день `X` теплее, чем дни, лежащие в стеке под ним.
- Если текущий день холоднее — мы просто кладем его в стек "в ожидании лучших времен". Таким образом, температуры в стеке всегда будут идти строго по убыванию (отсюда название "монотонный").

### 2. Алгоритм

1. Создать массив ответов `answer` такого же размера, как `temperatures`, заполненный нулями.
2. Создать пустой стек `stack` (в Python это обычный список, где мы используем `append` и `pop`).
3. Запустить цикл по массиву, получая индекс `i` и текущую температуру `current_temp`:
   - Пока стек не пуст И `current_temp` больше, чем температура дня, индекс которого лежит на вершине стека:
     - Достать этот индекс из стека: `prev_day = stack.pop()`.
     - Вычислить количество дней ожидания: `answer[prev_day] = i - prev_day`.
   - Положить текущий индекс `i` в стек: `stack.append(i)`.
4. Вернуть массив `answer`.

---

## Анализ сложности

- **Сложность по времени (Time Complexity):** O(N). Мы проходим по массиву один раз. Каждый индекс помещается в стек ровно один раз и извлекается из стека максимум один раз. Поэтому внутренний цикл `while` в сумме за весь алгоритм сделает не более N итераций.
- **Сложность по памяти (Space Complexity):** O(N). В худшем случае (если температуры идут строго по убыванию, как в Примере 3), мы положим все N индексов в стек, так и не дождавшись потепления.

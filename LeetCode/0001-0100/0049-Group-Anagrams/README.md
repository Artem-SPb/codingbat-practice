# [49. Group Anagrams](https://leetcode.com/problems/group-anagrams/)

## Описание задачи

Дан массив строк `strs`. Необходимо сгруппировать анаграммы вместе. Вы можете вернуть ответ в любом порядке.

**Анаграмма** — это слово или фраза, образованная путем перестановки букв другого слова или фразы (обычно используются все исходные буквы ровно один раз).

**Пример 1:**

- **Input:** strs = ["eat","tea","tan","ate","nat","bat"]
- **Output:** [["bat"],["nat","tan"],["ate","eat","tea"]]
- **Пояснение:** "eat", "tea" и "ate" состоят из одних и тех же букв, поэтому они в одной группе.

**Пример 2:**

- **Input:** strs = [""]
- **Output:** [[""]]

**Пример 3:**

- **Input:** strs = ["a"]
- **Output:** [["a"]]

---

## Мой подход к решению

### 1. Размышления (Thought Process)

- **Суть проблемы:** Нам нужно как-то понять, что `"eat"` и `"tea"` — это одно и то же. То есть нам нужен некий универсальный «ключ», который будет одинаковым для всех анаграмм одной группы.
- **Идея ключа:** Если мы возьмем слова `"eat"`, `"tea"` и `"ate"` и отсортируем буквы в каждом из них по алфавиту, то во всех трех случаях получим одну и ту же строку: `"aet"`.
- **Использование Хеш-таблицы (Словаря):** Мы можем создать словарь, где **ключом** будет отсортированная строка (например, `"aet"`), а **значением** — список всех исходных слов, которые при сортировке дают этот ключ (`["eat", "tea", "ate"]`).
- **Альтернативный ключ (Оптимизация):** Сортировка каждой строки занимает время. Поскольку мы знаем, что строки состоят только из строчных английских букв (их всего 26), мы можем создать кортеж из 26 чисел, где каждое число — это частота появления конкретной буквы. Кортеж `(1, 0, 0, 0, 1, ..., 1)` (одна 'a', одна 'e', одна 't') тоже может быть отличным ключом для словаря! Но для начала реализуем более интуитивный вариант с сортировкой, так как в Python он работает невероятно быстро и читается лаконично.

### 2. Алгоритм (через сортировку)

1. Создать словарь `anagram_map`. Удобно использовать `defaultdict(list)` из модуля `collections`, чтобы не проверять каждый раз, существует ли ключ.
2. Пройти циклом по каждому слову `s` в массиве `strs`:
   - Отсортировать слово по алфавиту. В Python `sorted(s)` возвращает список букв, поэтому оборачиваем его в `tuple` или склеиваем обратно в строку `"".join(sorted(s))`, так как ключом словаря может быть только неизменяемый тип данных.
   - Добавить исходное слово `s` в список по этому ключу: `anagram_map[key].append(s)`.
3. Вернуть все значения словаря (списки сгруппированных слов) в виде списка: `list(anagram_map.values())`.

---

## Анализ сложности

- **Сложность по времени (Time Complexity):** $O(N \cdot K \log K)$, где $N$ — количество строк в массиве, а $K$ — максимальная длина одной строки. Мы проходим по $N$ строкам, и каждую сортируем за $O(K \log K)$.
- **Сложность по памяти (Space Complexity):** $O(N \cdot K)$. Словарь будет хранить все $N$ строк, каждая из которых имеет длину до $K$ символов.

# [53. Maximum Subarray](https://leetcode.com/problems/maximum-subarray/)

## Описание задачи

Дан целочисленный массив `nums`. Необходимо найти непрерывный подмассив (содержащий хотя бы одно число), который имеет наибольшую сумму, и вернуть эту сумму.

**Подмассив** — это непрерывная часть массива.

**Пример 1:**

- **Input:** nums = [-2,1,-3,4,-1,2,1,-5,4]
- **Output:** 6
- **Пояснение:** Подмассив [4,-1,2,1] имеет наибольшую сумму = 6.

**Пример 2:**

- **Input:** nums = [1]
- **Output:** 1

**Пример 3:**

- **Input:** nums = [5,4,-1,7,8]
- **Output:** 23

---

## Мой подход к решению

### 1. Размышления (Thought Process)

У этой задачи есть два классических пути решения:

**Путь 1: Разделяй и властвуй (Divide and Conquer) — Время O(N log N)**

- Идея состоит в том, чтобы разделить массив ровно пополам.
- Искомый максимальный подмассив может находиться только в трех местах:
  1. Целиком в левой половине.
  2. Целиком в правой половине.
  3. Пересекать середину (начинаться в левой и заканчиваться в правой).
- Мы можем рекурсивно найти максимумы для левой и правой половин, а затем найти максимальный подмассив, пересекающий центр (линейным проходом от центра к краям). Результатом будет максимум из этих трех значений. Это отличный пример парадигмы, но он не самый быстрый.

**Путь 2: Алгоритм Кадане (Kadane's Algorithm) — Время O(N) — Оптимальный**

- Это элегантный подход на стыке жадных алгоритмов и динамического программирования.
- Идем по массиву слева направо. На каждом шаге мы задаем себе один вопрос: **"Стоит ли мне присоединить текущее число к уже существующему подмассиву, или лучше начать новый подмассив прямо с этого числа?"**
- Ответ прост: если накопленная сумма предыдущего подмассива стала отрицательной, она будет только "тянуть на дно" наше текущее число. В таком случае мы отбрасываем старую сумму и начинаем отсчет заново с текущего элемента.
- Попутно мы обновляем глобальный максимум `max_sum`.

### 2. Алгоритм (Кадане)

1. Инициализируем `current_sum = 0` (текущая сумма) и `max_sum = nums[0]` (глобальный рекорд).
2. Запускаем цикл по каждому числу `num` в массиве `nums`:
   - Если `current_sum < 0`, мы сбрасываем её в `0` (отказываемся от убыточного багажа).
   - Прибавляем текущее число: `current_sum += num`.
   - Обновляем глобальный рекорд: `max_sum = max(max_sum, current_sum)`.
3. Возвращаем `max_sum`.

---

## Анализ сложности

- **Сложность по времени (Time Complexity):** O(N), где N — длина массива. Мы проходим по массиву ровно один раз.
- **Сложность по памяти (Space Complexity):** O(1). Мы используем только две переменные для отслеживания сумм, без выделения дополнительной памяти.

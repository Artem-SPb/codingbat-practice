# [75. Sort Colors](https://leetcode.com/problems/sort-colors/)

## Описание задачи

Дан массив `nums`, состоящий из `n` объектов, окрашенных в красный, белый или синий цвет. Необходимо отсортировать их **на месте** (in-place) так, чтобы объекты одного цвета располагались рядом друг с другом, а цвета шли в порядке: красный, белый, синий.

Мы используем целые числа `0`, `1` и `2` для обозначения красного, белого и синего цветов соответственно.

Вы должны решить эту задачу, не используя встроенную функцию сортировки библиотеки.

**Строгое ограничение:** Желательно решить задачу за один проход, используя только O(1) дополнительной памяти.

**Пример 1:**

- **Input:** nums = [2,0,2,1,1,0]
- **Output:** [0,0,1,1,2,2]

**Пример 2:**

- **Input:** nums = [2,0,1]
- **Output:** [0,1,2]

## Мой подход к решению

### 1. Размышления (Thought Process)

- **Почему не обычная сортировка?** Сортировка выбором или слиянием сделает слишком много лишней работы, сравнивая элементы между собой. Здесь мы заранее знаем все возможные значения: только 0, 1 и 2.
- **Подход со счетчиками (Два прохода):** Самый простой путь — пройти по массиву один раз и посчитать, сколько у нас нулей, единиц и двоек. На втором проходе просто перезаписать массив этим количеством нулей, потом единиц, потом двоек. Это работает за время **O(N)**, но требует **двух проходов**. На собеседованиях всегда просят сделать за один.
- **Алгоритм "Голландский флаг" (Три указателя):** Мы можем использовать три указателя: `left` (для нулей), `curr` (для текущего элемента) и `right` (для двоек).
  - Наша цель — скидывать все встреченные нули в левую часть массива, а все двойки — в правую. Единицы при этом автоматически окажутся зажатыми в центре.

### 2. Алгоритм

1. Инициализируем три указателя: `left = 0`, `curr = 0`, `right = len(nums) - 1`.
2. Запускаем цикл, пока `curr <= right`:
   - **Если `nums[curr] == 0`**: Мы нашли ноль. Его нужно отправить в начало. Меняем местами `nums[curr]` и `nums[left]`. Сдвигаем оба указателя `left` и `curr` вправо.
   - **Если `nums[curr] == 1`**: Единица уже на своем месте (в центре). Просто сдвигаем `curr` вправо.
   - **Если `nums[curr] == 2`**: Мы нашли двойку. Её нужно отправить в конец. Меняем местами `nums[curr]` и `nums[right]`. Сдвигаем `right` влево. **Важно:** `curr` мы не сдвигаем, потому что на место `curr` пришел новый элемент из конца массива, и его тоже нужно будет проверить на следующем шаге.
3. Массив отсортирован in-place.

## Анализ сложности

- **Сложность по времени (Time Complexity):** **O(N)**. Мы проходим по массиву ровно один раз. Каждый элемент обрабатывается (и переставляется) за константное время.
- **Сложность по памяти (Space Complexity):** **O(1)**. Мы используем только три переменные-указателя для перестановки элементов прямо внутри исходного массива.

# [560. Subarray Sum Equals K](https://leetcode.com/problems/subarray-sum-equals-k/)

## Описание задачи

Дан массив целых чисел `nums` и целое число `k`. Необходимо вернуть общее количество непрерывных подмассивов, сумма элементов которых равна `k`.

**Пример 1:**

- **Input:** nums = [1,1,1], k = 2
- **Output:** 2
- **Пояснение:** Есть два подмассива с суммой 2: [1, 1] (первые два элемента) и [1, 1] (последние два элемента).

**Пример 2:**

- **Input:** nums = [1,2,3], k = 3
- **Output:** 2
- **Пояснение:** Подмассивы с суммой 3: [1, 2] и [3].

---

## Мой подход к решению

### 1. Размышления (Thought Process)

- **Подход "в лоб" (Brute-force):** Мы могли бы использовать два вложенных цикла, чтобы проверить сумму каждого возможного подмассива. Но для массива из 20 000 элементов это даст 400 миллионов операций — алгоритм упадет с ошибкой "Time Limit Exceeded".
- **Идея префиксных сумм (Prefix Sum):** Представьте, что мы идем по массиву и постоянно накапливаем сумму. Эта текущая сумма называется "префиксной".
- **Математический трюк:** Если на текущем шаге наша накопленная сумма равна `current_sum`, а мы ищем подмассив с суммой `k`, то нам нужно понять, встречалась ли нам раньше префиксная сумма, равная `current_sum - k`.
  - _Почему?_ Потому что если мы "отрежем" эту старую сумму от текущей, то в остатке (в подмассиве между ними) как раз и будет ровно `k`!
- **Хеш-таблица спешит на помощь:** Нам нужно где-то быстро (за O(1)) проверять, встречалась ли нам раньше сумма `current_sum - k`. Для этого мы создаем словарь, где:
  - **Ключ:** значение префиксной суммы.
  - **Значение:** сколько раз эта сумма нам встречалась.
- **Базовый случай:** Важно изначально положить в словарь `{0: 1}` (сумма 0 встретилась 1 раз). Это нужно для того случая, когда нужный нам подмассив начинается прямо с нулевого индекса (самого начала массива).

### 2. Алгоритм

1. Инициализировать `count = 0` (счетчик найденных подмассивов) и `current_sum = 0` (текущая накопленная сумма).
2. Создать словарь `prefix_sums = {0: 1}`.
3. Запустить цикл по каждому числу `num` в массиве:
   - Прибавить `num` к `current_sum`.
   - Вычислить "целевую" старую сумму: `target = current_sum - k`.
   - Если `target` есть в словаре `prefix_sums`, значит мы нашли подмассив(ы)! Увеличиваем `count` на то количество раз, которое этот `target` встречался в прошлом: `count += prefix_sums[target]`.
   - Добавить саму `current_sum` в словарь (или увеличить её счетчик на 1, если она уже там есть), чтобы будущие элементы могли использовать её для образования подмассивов.
4. Вернуть `count`.

---

## Анализ сложности

- **Сложность по времени (Time Complexity):** **O(N)**, где N — длина массива. Мы проходим по массиву один раз, а поиск и вставка в хеш-таблицу занимают O(1).
- **Сложность по памяти (Space Complexity):** **O(N)**. В худшем случае (когда все элементы положительные, и каждая префиксная сумма уникальна) словарь будет хранить N различных ключей.
